Assembly notes

Частина 1: Лабораторна робота №1

Тема: Розробка застосунку для обчислення результату математичного виразу на мові Асемблер.

Мета і задачі: вивчити способи адресації даних мікропроцесором i8086 і їх використання при пересиланні даних, арифметичні команди мікропроцесора i8086 і правила їх використання, ознайомитись з основними форматами і правилами роботи з командами множення і ділення мікропроцесора i8086. Вивчити основні відомості і визначення подані у лекції.

Програмна модель МП 8086

Програмна модель – це засоби які представлені програмісту для реалізації програм. До неї входять регістри загального призначення, сегментні регістри, вказівники, індексні регістри та спеціальні регістри прапорів.

Регістри загального призначення

КатегоріяНазваСтруктураОпис

Сегментні регістри, Вказівники та Індекси

  • CS (Code Segment): 16-біт. Базова адреса сегмента коду (разом з IP).
  • DS (Data Segment): 16-біт. Базова адреса сегмента даних.
  • SS (Stack Segment): 16-біт. Базова адреса сегмента стека.
  • ES (Extra Segment): 16-біт. Додатковий сегмент для рядкових/пам’ятних операцій.
  • SP (Stack Pointer): 16-біт. Вказівник вершини стека (разом з SS).
  • BP (Base Pointer): 16-біт. Вказівник бази, доступ до даних у стеку.
  • SI (Source Index): 16-біт. Джерело в рядкових операціях.
  • DI (Destination Index): 16-біт. Приймач у рядкових операціях.

Регістр прапорців (FLAGS)

16-бітний регістр. Прапори стану:
CF (перенесення),
PF (паритету),
AF (додаткове перенесення),
ZF (нуля),
SF (знака),
TF (трасування),
IF (переривання),
DF (напрямку),
OF (переповнення).

Режими адресації даних

Мікропроцесор i8x86 має 24 режими адресації операндів. Вони розділені на 7 груп:

  • Регістровий: формат регістр (Приклад: MOV AX, BX).
  • Безпосередній: формат дані (Приклад: MOV AX, 1234h).
  • Прямий: формат зсув/мітка (Приклад: MOV AX, [1234h]).
  • Непрямий регістровий: формат [BX], [BP], [DI], [SI] (Приклад: MOV AX, [BX]).
  • По базі: формат [BX]+зсув, [BP]+зсув (Приклад: MOV AX, [BX+4]).
  • Прямий з індексуванням: формат [DI]+зсув, [SI]+зсув (Приклад: MOV AX, [SI+100h]).
  • По базі з індексуванням: формат [BX][SI]+зсув (Приклад: MOV AX, [BX+SI]).

Команди Assembler

  • XCHG: Обмін значеннями двох операндів (регістр-пам'ять, пам'ять-регістр, регістр-регістр). Приклад: XCHG AL, AH.
  • MOV: Копіювати значення з операнд2 в операнд1. Не змінює прапорців. Інструкція MOV не може встановлювати значення CS та IP, копіювати з одного сегментного регістра в інший або копіювати безпосереднє значення в сегментний регістр.
  • ADC: Додавання з перенесенням (операнд1 = операнд1 + операнд2 + CF).
  • ADD: Додати (операнд1 = операнд1 + операнд2).
  • SBB: Відніміть за допомогою позики (операнд1 = операнд1 - операнд2 - CF).
  • SUB: Відніміть (операнд1 = операнд1 - операнд2).
  • MUL: Беззнакове множення. Якщо операнд байт: AX = AL * операнд. Якщо слово: DX:AX = AX * операнд.
  • IMUL: Множення зі знаком.
  • DIV: Беззнакове ділення. Якщо операнд байт: AL = AX / операнд, AH = залишок. Якщо слово: AX = (DX:AX) / операнд, DX = залишок.
  • IDIV: Ділення зі знаком.

Допоміжні функції (emu8086.inc)

  • PUTC char: макрос, виводить ASCII-символ у поточній позиції курсора (наприклад, PUTC 10 - новий рядок).
  • PRINT string: макрос, виводить рядок.
  • PRINTN string: макрос, виводить рядок і автоматично додає "повернення каретки" в кінці.
  • PRINT_STRING: процедура для виведення рядка, що закінчується нулем.
  • SCAN_NUM: процедура, яка отримує багатозначне число зі знаком з клавіатури та зберігає результат у CX.
  • PRINT_NUM: процедура, яка друкує знакове число з регістру AX.

Директиви розподілу пам’яті (Лекція 3-4)

Синтаксис: ім'я_змінної D* значення.

  • DB — визначити байт.
  • DW — визначити слово (2 байти).
  • DD — визначити подвійне слово (4 байти).
  • DF — визначити 6 байт (16-бітний селектор : 32-бітний зсув).
  • DQ — визначити учетверене слово (8 байт).
  • DT — визначити 10 байт (80-бітні типи даних FPU).

Якщо потрібно заповнити ділянку пам'яті даними, що повторюються, використовується спеціальний оператор DUP (наприклад: table_512w dw 512 dup (?)).

Структури

Директива STRUC дозволяє визначити структуру даних. Звертання до елементів структури здійснюється через оператор «.» (крапка).

point struc
  x dw 0
  y dw 0
point ends
cur_point point <1,1>
mov ax, cur_point.x

Правила проведення обчислення виразу

  1. Визначення пріоритетності операції:
    • Дужки () — виконуються першими, від внутрішніх до зовнішніх.
    • Унарні операції (знак +, -, інкремент/декремент).
    • Множення і ділення (*, /, DIV, MUL) — зліва направо.
    • Додавання і віднімання (+, -, ADD, SUB).
    • Порівняння та логічні операції.
  2. Приведення операндів до максимальної розрядності.
  3. Формування змінних, визначення глибини стека.
  4. Обчислення.

Команди передачі керування (Лекція 5-6)

Команди переходів можна розділити на три групи:

  1. Команди безумовної передачі керування (безумовний перехід, виклик/повернення з процедури, переривання).
  2. Команди умовної передачі керування (по результату порівняння, по стану прапора, по вмісту регістра ecx/cx).
  3. Команди керування циклом (із лічильником cx/ecx та додатковими умовами).

Мітки

Символічне ім’я, що позначає комірку пам’яті. Атрибути: ім’я сегмента, зміщення, тип мітки (near/far). Описується через : або директивою label.

Команди безумовного переходу

jmp [модифікатор] адрес_переходу — перехід без зберігання інформації про точку повернення. Внутрішньосегментний перехід змінює тільки вміст eip/ip і буває: прямий короткий (від –128 до +127 байтів), прямий (до 64 Кбайт), непрямий (через регістр).

Умовні переходи та прапори

Перевіряють відношення зі знаком, без знака або стан прапорів. Синтаксис: j(хх) мітка_перехода.

МнемокодКритерій переходуЗначення прапорів
je / jzоперанд_1 = операнд_2zf=1
jne / jnzоперанд_1 != операнд_2zf=0
jl / jngeоперанд_1 < операнд_2 (зі знаком)sf!=of
jg / jnleоперанд_1 > операнд_2 (зі знаком)sf=of і zf=0
jb / jnaeоперанд_1 < операнд_2 (без знака)cf=1
ja / jnbeоперанд_1 > операнд_2 (без знака)cf=0 і zf=0

Команда cmp віднімає операнди і порівнює прапори: cmp операнд_1, операнд_2.

Організація циклів

Використовує три команди (працюють з лічильником cx/ecx):

  • loop мітка: декремент cx; якщо cx > 0, перехід на мітку.
  • loope/loopz мітка: повторити цикл, поки cx != 0 АБО zf=1.
  • loopne/loopnz мітка: повторити цикл, поки cx != 0 АБО zf=0.

Типи циклів: Цикл з післяумовою (тіло виконується хоча б один раз) та Цикл з передумовою (якщо умова хибна, тіло не виконається жодного разу).
